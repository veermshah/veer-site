---
title: "V0106: model mismatch"
description: "Veer diagnostic V0106"
---

Two contexts that must belong to the same model (for example the result of `commit` and the speculated context, or a function argument and parameter) were opened on different models.

## Example

```veer
model a = "x" { layers: 1, kv_heads: 1, head_dim: 8 }
model b = "y" { layers: 1, kv_heads: 1, head_dim: 8 }
fn f(c: Ctx<a>) { drop c }
fn main() { f(open b) }
```

```text
error[V0106]: expected a context of model `a`, found `b`
  --> example.veer:4:15
  |
4 | fn main() { f(open b) }
  |               ^^^^^^ 
   = help: run `veer explain V0106` for details
```
