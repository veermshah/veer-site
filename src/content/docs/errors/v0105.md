---
title: "V0105: context cannot be duplicated"
description: "Veer diagnostic V0105"
---

A context may not be stored twice, put in a non-destructured tuple, or used where a copy would be made. Use `fork` to get two handles that share the KV-cache prefix.

## Example

```veer
model m = "x" { layers: 1, kv_heads: 1, head_dim: 8 }
fn main() { let c = open m
 let t = (c, 1) }
```

```text
error[V0105]: a value of type (Ctx<m>, int) contains a context and must be destructured, e.g. `let (c, x) = ...`
  --> example.veer:3:6
  |
3 |  let t = (c, 1) }
  |      ^ 
   = help: run `veer explain V0105` for details
```
