---
title: "V0110: type mismatch"
description: "Veer diagnostic V0110"
---

An expression has a different type than the position requires.

## Example

```veer
fn main() { let x: int = "text" }
```

```text
error[V0110]: expected int, found str<=4
  --> example.veer:1:26
  |
1 | fn main() { let x: int = "text" }
  |                          ^^^^^^ 
   = help: run `veer explain V0110` for details
```
