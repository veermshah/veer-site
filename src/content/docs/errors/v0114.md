---
title: "V0114: recursion is not allowed"
description: "Veer diagnostic V0114"
---

Veer forbids recursive functions so that every program has a finite, statically analyzable context graph.

## Example

```veer
fn f() { f() }
```

```text
error[V0114]: function `f` is recursive
  --> example.veer:1:4
  |
1 | fn f() { f() }
  |    ^ 
   = help: run `veer explain V0114` for details
```
