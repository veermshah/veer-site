---
title: "V0119: duplicate definition"
description: "Veer diagnostic V0119"
---

Two items, parameters, or fields have the same name.

## Example

```veer
fn f() {}
fn f() {}
```

```text
error[V0119]: `f` is defined more than once
  --> example.veer:2:4
  |
2 | fn f() {}
  |    ^ 
  ::: example.veer:1:4
  |
1 | fn f() {}
  |    ^ first defined here
   = help: run `veer explain V0119` for details
```
