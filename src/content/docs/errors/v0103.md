---
title: "V0103: branches disagree about a context"
description: "Veer diagnostic V0103"
---

After an `if`/`else`, every context that existed before must be in the same state (live or consumed) on both paths. Otherwise the program would not know, after the branch, whether the KV cache still exists.

## Example

```veer
model m = "x" { layers: 1, kv_heads: 1, head_dim: 8 }
fn main() {
  let c = open m
  if true { drop c }
}
```

```text
error[V0103]: context `c` is consumed on one branch but not the other
  --> example.veer:4:3
  |
4 |   if true { drop c }
  |   ^^^^^^^^^^^^^^^^^^ 
   = note: consume (or keep) it on both paths
   = help: run `veer explain V0103` for details
```
