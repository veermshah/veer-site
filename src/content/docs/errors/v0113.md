---
title: "V0113: unbounded loop"
description: "Veer diagnostic V0113"
---

Loops must have a statically known trip count (`for i in 0..N` with constant `N`, or iteration over a bounded list). This is what lets the planner bound KV memory and prefill cost.

## Example

```veer
fn f(n: int) { for i in 0..n { } }
```

```text
error[V0113]: loop bounds must be constants
  --> example.veer:1:28
  |
1 | fn f(n: int) { for i in 0..n { } }
  |                            ^ 
   = note: Veer needs a static trip count to bound KV memory and prefill cost
   = help: run `veer explain V0113` for details
```
