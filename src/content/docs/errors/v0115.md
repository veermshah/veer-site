---
title: "V0115: unknown field"
description: "Veer diagnostic V0115"
---

The schema or model declaration has no field with this name.

## Example

```veer
schema S { a: int }
fn g(s: S) -> int { return s.b }
```

```text
error[V0115]: schema `S` has no field `b`
  --> example.veer:2:30
  |
2 | fn g(s: S) -> int { return s.b }
  |                              ^ 
   = help: run `veer explain V0115` for details
```
