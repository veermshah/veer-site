---
title: "V0116: structured output does not fit"
description: "Veer diagnostic V0116"
---

The smallest valid output for this `json<T>` schema or `choice[...]` needs more tokens than `max` allows, so the generation could never succeed.

## Example

```veer
schema S { name: str<=10, age: int }
model m = "x" { layers: 1, kv_heads: 1, head_dim: 8 }
fn main() { let (c, s) = gen open m max 2 as json<S>
 drop c }
```
