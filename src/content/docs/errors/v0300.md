---
title: "V0300: tensor shape mismatch"
description: "Veer diagnostic V0300"
---

The static shapes of tensors are incompatible, for example `[1, 256] @ [128, 64]`.

## Example

```veer
fn main() { let a = zeros([1, 4])
 let b = zeros([3, 2])
 let c = a @ b }
```

```text
error[V0300]: cannot multiply shapes [1, 4] @ [3, 2]
  --> example.veer:3:10
  |
3 |  let c = a @ b }
  |          ^^^^^ 
   = help: run `veer explain V0300` for details
```
