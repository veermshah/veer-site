---
title: "V0117: unbounded string appended to a context"
description: "Veer diagnostic V0117"
---

Only strings with a static bound (`str<=N`) may be appended to a context, otherwise KV memory could not be bounded.

## Example

```veer
model m = "x" { layers: 1, kv_heads: 1, head_dim: 8 }
fn f(s: str) { let c = open m ++ s
 drop c }
```
