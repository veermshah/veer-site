---
title: "V0121: duplicate span label"
description: "Veer diagnostic V0121"
---

A context may contain each span label at most once, so that `splice` is unambiguous.

## Example

```veer
model m = "x" { layers: 1, kv_heads: 1, head_dim: 8 }
fn main() { let c = open m ++ #[a] "x" ++ #[a] "y"
 drop c }
```

```text
error[V0121]: span `a` is already present in this context
  --> example.veer:2:45
  |
2 | fn main() { let c = open m ++ #[a] "x" ++ #[a] "y"
  |                                             ^ 
   = help: run `veer explain V0121` for details
```
