---
title: "V0100: unknown name"
description: "Veer diagnostic V0100"
---

A variable, function, model, prefix, tool, schema or constant was used but never declared in scope.

## Example

```veer
fn main() { print(nope) }
```

```text
error[V0100]: unknown name `nope`
  --> example.veer:1:19
  |
1 | fn main() { print(nope) }
  |                   ^^^^ 
   = help: run `veer explain V0100` for details
```
