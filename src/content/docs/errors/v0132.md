---
title: "V0132: statement not allowed here"
description: "Veer diagnostic V0132"
---

`return` is not allowed inside `speculate`, and `commit`/`rollback` are only allowed inside `speculate`.

## Example

```veer
fn main() { rollback 1 }
```

```text
error[V0132]: `rollback` is only allowed inside `speculate`
  --> example.veer:1:13
  |
1 | fn main() { rollback 1 }
  |             ^^^^^^^^^^ 
   = help: run `veer explain V0132` for details
```
