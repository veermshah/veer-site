---
title: "V0111: wrong number of arguments"
description: "Veer diagnostic V0111"
---

A function, tool, or builtin was called with the wrong number of arguments.

## Example

```veer
fn f(x: int) -> int { return x }
fn main() { print(f(1, 2)) }
```

```text
error[V0111]: `f` takes 1 argument(s), 2 given
  --> example.veer:2:19
  |
2 | fn main() { print(f(1, 2)) }
  |                   ^^^^^^^ 
   = help: run `veer explain V0111` for details
```
