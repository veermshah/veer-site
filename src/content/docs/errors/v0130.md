---
title: "V0130: speculation must end in commit or rollback"
description: "Veer diagnostic V0130"
---

Every path through a `speculate` block must end with `commit (ctx, value)` or `rollback value`. That is what makes speculation transactional.

## Example

```veer
model m = "x" { layers: 1, kv_heads: 1, head_dim: 8 }
fn main() {
  let c = open m
  let (c, v) = speculate c { let x = 1 }
  drop c
}
```

```text
error[V0130]: this path through `speculate` falls off the end
  --> example.veer:4:40
  |
4 |   let (c, v) = speculate c { let x = 1 }
  |                                        ^ 
   = note: end every path with `commit (ctx, value)` or `rollback value`
   = help: run `veer explain V0130` for details
```
