---
title: "V0112: string bound exceeded"
description: "Veer diagnostic V0112"
---

Strings carry a static upper bound on their token count (`str<=N`). An expression whose bound is larger than the declared bound cannot be stored there. Increase the declared bound or shorten the expression.

## Example

```veer
fn f() -> str<=3 { return "far too long" }
```

```text
error[V0112]: string may be up to 12 tokens, but at most 3 are allowed
  --> example.veer:1:27
  |
1 | fn f() -> str<=3 { return "far too long" }
  |                           ^^^^^^^^^^^^^^ 
   = help: run `veer explain V0112` for details
```
