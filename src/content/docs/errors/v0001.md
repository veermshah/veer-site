---
title: "V0001: invalid token"
description: "Veer diagnostic V0001"
---

The lexer found a character or literal it does not understand, for example an unterminated string or a stray `$`.

## Example

```veer
let s = "unterminated
```

```text
error[V0001]: unterminated string literal
  --> example.veer:1:9
  |
1 | let s = "unterminated
  |         ^^^^^^^^^^^^^ 
   = help: run `veer explain V0001` for details
```
