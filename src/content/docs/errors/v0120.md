---
title: "V0120: unknown span"
description: "Veer diagnostic V0120"
---

`splice c at name` requires that `name` labels a region (`#[name]`) that is present in the context `c`.

## Example

```veer
model m = "x" { layers: 1, kv_heads: 1, head_dim: 8 }
fn main() { let c = open m ++ "hi"
 let c = splice c at doc with "x"
 drop c }
```

```text
error[V0120]: context has no span `doc`
  --> example.veer:3:22
  |
3 |  let c = splice c at doc with "x"
  |                      ^^^ 
   = note: this context has no labelled spans; add one with `c ++ #[name] text`
   = help: run `veer explain V0120` for details
```
