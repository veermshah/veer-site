# Veer website

Docs and downloads for the [Veer language](https://veer-lang.vercel.app): a language where LLM contexts are typed, linear values and the compiler proves KV-cache memory, cost, and numeric accuracy.

Built with [Astro Starlight](https://starlight.astro.build) and deployed on Vercel. Release binaries for macOS, Windows, and Linux are published to this repository's [Releases](https://github.com/veermshah/veer-site/releases).

```sh
npm install
npm run dev      # local preview
npm run build    # static site in dist/
```

Pages under `src/content/docs/cookbook/` and `src/content/docs/errors/` are generated from the toolchain.
